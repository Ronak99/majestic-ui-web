Majestic UI is a lightweight documentation site for the `majestic_ui` CLI.
Instead of installing a heavy package, you add the widget source directly to
your Flutter project:

```bash
majestic_ui add star_rush_background
```

The imported code belongs to your app. You can edit styles, animation timing,
layout, and behavior without waiting on a package release.

## What Belongs Here

- CLI installation and usage.
- Widget documentation.
- Preview URLs.
- Dependencies required by each widget.
- Source files copied by the CLI.

New docs are plain MDX files under `content/docs`, so changing copy or adding a
widget does not require a database, auth flow, GitHub scan, or deploy-time data
fetch.
